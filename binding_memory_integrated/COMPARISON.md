# 两份数据的异同与整合决策

| 项目 | 本次主实验 `core/` | `binding_dataset.zip` 补充基准 |
| --- | --- | --- |
| 共同目标 | 判断测试物体的颜色、形状、纹理三项是否在同一学习物体上出现 | 相同 |
| 颜色 | 红、蓝、绿、黄、紫、橙 | 相同 |
| 形状 | 圆、方、三角、六边形、星形、菱形 | 圆、方、三角、星形、十字、半圆 |
| 纹理 | 圆点、斜条纹、网格、棋盘格、波纹、折线纹 | 纯色、横条纹、竖条纹、斜条纹、圆点、棋盘格 |
| 学习图 | 4、8、12 张 | 固定 3 张 |
| 视觉干扰 | 0 或 4 张 | 无 |
| 每组测试 | 3 真正出现 + 3 种诱饵，各 1 张 | 1 真正出现 + 4 种诱饵，各 1 张 |
| 总量 | 144 组、864 题 | 350 组、1,750 题 |
| YES/NO | 432/432 | 350/1,400 |
| 图片 | 384×384 PNG | 448×448 PNG |
| 划分 | 按种子拆分，dev 216 题、test 648 题 | dev 250 题、test 1,500 题 |

两份数据都使用单张、居中的无文字物体图片，均有真正出现、重组、近似、无关诱饵，也都有可追溯的生成与验证材料。压缩包提供了更成熟的模型输入与答案隔离、开发/测试分集、感知校准图片、结构难度注释和独立重绘测试图。

**关键约束差异：** 设计简述规定，关键重组诱饵任意两项属性都不能在同一学习物体中配对。压缩包的 `critical_1plus1plus1` 满足这个要求；其 `critical_2plus1` 刻意保留一对已见属性，350 道该类题均违反此要求。压缩包的 `near_2seen` 保留一对已见属性，且全新属性可以是任一维；主实验的近似诱饵固定为全新颜色、已见形状和纹理，与设计样图一致。

因此整合包以 `core/` 作为简述对应的主实验。已将压缩包的输入/答案隔离、开发/测试分集、校准图片、难度字段、无语义文件名和重新渲染查询图片引入主实验。压缩包原数据作为补充基准完整保留其有效数据与来源代码，用于另行考察 3 学习图条件下的表现；两轨道的准确率分别计算。

补充基准的内部验证报告显示其自身格式和标签检查通过。本整合包再次独立核对了试次数、图片引用与诱饵配对条件。两轨道都还没有实际 VLM 感知校准或正式模型结果。
