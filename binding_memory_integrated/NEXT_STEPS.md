# 后续实验流程

1. **先检查刺激可辨认性。** 查看 `core/calibration/inputs.jsonl` 的 432 张变体，分别让待测视觉语言模型识别颜色、形状和纹理；用 `core/calibration/labels.jsonl` 判分。重点检查网格/棋盘格、波纹/折线纹，以及六边形/菱形的混淆。校准会话应与正式试次隔离，不把图片目录、文件名或标签发给模型。
2. **在开发集确定流程。** 用 `core/inputs/dev.jsonl` 的 216 题调试图片提交顺序、固定提示词、模型版本、温度、图片分辨率处理和 YES/NO 解析规则。开发集按种子 1–6 划分；测试集为种子 7–24。确定后记录配置并冻结，再开始测试集。
3. **逐题运行，逐题新会话。** 每次提交学习图 4/8/12 张，按数组顺序逐张呈现；若有干扰图，再逐张呈现 4 张；最后只呈现 1 张测试图并要求仅回答 YES 或 NO。每道题重新创建上下文，不在同一会话继续下一题。调用顺序可以整体随机，但每题内部的图片顺序不能改。不要把 `trial_id`、文件名、答案或诱饵类别发给模型。
4. **保存原始结果再判分。** 每题记录 `trial_id`、模型名与版本、时间、参数、原始回答、解析出的 YES/NO、是否无效。仅接受明确的 YES 或 NO；无效输出单独统计，按错误计入准确率。用 `core/labels/{dev,test}.jsonl` 通过 `trial_id` 连接标准答案。
5. **按条件报告结果。** 至少报告总体准确率、Target 命中率、关键重组/近似/无关诱饵各自的错误接受率，以及 4/8/12 学习量和 0/4 干扰量下的结果。特别比较同一种子、学习量、测试题在有无干扰条件下的配对差值。置信区间按种子或学习列表整组重采样，避免把共享学习图的题目当作完全独立样本。
6. **如需扩展实验，再单独跑补充基准。** 其输入在 `auxiliary/three_study_v0.1/data/v0.1/inputs/`。该轨道 20% YES、80% NO，总回答 NO 也会有 80% 准确率；应报告 Target 命中率和各诱饵错误接受率，不将其题目加进主实验的 864 题统计。

本任务测量模型在当前上下文中的物体属性绑定识别。由于学习图片仍在会话历史中，结果不能直接解释为跨会话的持久记忆。若研究目标是撤除原图后的保持能力，需要另定上下文清除、延迟与可见性协议。
